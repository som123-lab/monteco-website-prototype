# MONTECO website prototype

A responsive multi-page React + Vite prototype built from the supplied MONTECO brief.

## Run locally
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev` and open the local Vite URL.
4. Run `npm run build` for a production build.

## Stack
React, Vite, JavaScript, Tailwind CSS, React Router and Lucide React.

## Routes
Home; What We Do; Enterprise Advisory; Managed Services; Enterprise Talent; SAP; IFS; Data & AI; Odoo; Cybersecurity; Industries and six industry detail pages; Talent; About; Insights listing and detail pages; Careers; Contact.

## Prototype boundaries
- The homepage client strip deliberately uses labelled placeholders; no client logos were supplied.
- Architectural photography uses remote Unsplash image URLs as visual placeholders.
- The Kuala Lumpur presence is named without an invented street address.
- The Careers Manatal area is a clearly labelled placeholder, not an integration.
- Contact form validation runs in the browser. Submission shows a prototype confirmation only; no data is sent to a company inbox or persisted.
- Snowflake is represented as a navigation entry within the supplied certified alliances grouping; no partnership claim is made.
- Replace visual placeholders and connect approved production services before launch.

## Structure
`src/components`, `src/pages`, `src/layouts`, `src/data`, `src/styles`. Assets directory is reserved for approved brand and client assets.
